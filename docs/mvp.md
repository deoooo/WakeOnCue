# MVP 范围与验收

> 2026-11-05 重写。早期的 MVP 是「iPhone 可靠录音 → 分段上传到用户的 S3」，那条路已经停用：iPhone 不再上传 S3，录音只留在自己的设备上。早期范围见 git 历史里的 `docs/mvp.md`。

## 目标

用户每天戴着手表、带着 iPhone、开着 Mac，就能**不操心地录下一整天**，并在 Mac 上看到当天发生了什么：

```text
Mac 全天录音（内建麦克风）
  → 本机实时转录 → 每小时和每天的总结（带引用）→ 点句回放、搜索、导出

离开电脑时：Apple Watch 全程录音 → iPhone 中转 → 连上 Mac 后自动回传、合并进时间线
iPhone：单独录一段，或手表录音的中转站
```

可靠性优先级不变：**本地录音 > 不丢数据 > 交互 > 视觉效果**。

MVP 的标准是**用户能正常日常使用**：连续几天不需要人盯着，录不了时用户知道原因，录下来的内容能拿出来。

## 不在 MVP 里

- 线上会议：Mac 不录会议 App 的系统声音，也不做「会议对方」、会议面板、会议要点/纪要、日历关联和会议导出。
- 手表长静音置零（deoooo/WakeOnCue#6）：现有参数在真机上不触发，调参并确认不丢轻声之后再做。
- Mac：按 Wi-Fi 排除录音、App Intents、词表和手动改错、从通讯录选说话人、导入音频。
- 周视图和周报、待办和决定、多台 Mac 同步、Mac 的结果同步回 iPhone。
- 正式分发：Developer ID 签名、全天录音的法律和同意提示（上线前必须做）。
