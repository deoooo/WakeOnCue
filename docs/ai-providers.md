# 第三方语音识别与 AI 服务

默认全部在 iPhone 上完成：Apple Speech 负责转写，Apple 智能负责摘要和提问。两项都可以在 iOS「设置」里分别换成第三方服务。填写的 API 密钥只保存在这台 iPhone 的钥匙串（`ThisDeviceOnly`）。

| 能力 | 可选服务 | 协议 |
|---|---|---|
| 录音后转写 | Apple Speech（默认）、OpenAI 兼容 API | `POST {base}/audio/transcriptions` |
| 摘要与提问 | Apple 智能（默认）、OpenAI 兼容 API | `POST {base}/chat/completions` |
| 摘要与提问 | Claude API | `POST {base}/v1/messages` |

语音识别没有正式的行业标准，但 OpenAI 的 `/audio/transcriptions` 是事实标准，所以只要实现了这个接口的服务或自托管程序都能接入，例如 Groq（`https://api.groq.com/openai/v1`）。Anthropic 没有语音识别接口，因此转写没有 Claude 选项。

iPhone 没有实时字幕，也不区分说话人：转写在录音结束后进行。

## 填写方式

- **服务地址**：留空时使用官方地址（`https://api.openai.com/v1`、`https://api.anthropic.com`）。OpenAI 兼容服务填到 `/v1` 这一级，不要包含 `/chat/completions`。
- **模型**：必填。转写模型建议用能返回时间戳的模型，例如 `whisper-1`、`whisper-large-v3-turbo`。
- **API 密钥**：公网服务必填；局域网内的服务可以留空。
- **地址限制**：公网只允许 HTTPS，明文 HTTP 仅限 `localhost`、`.local` 和私有网段，避免密钥被明文发送。

保存时会实际调用一次服务来检查配置（转写发送一秒静音，模型发送一条极短的消息），可能产生很少的费用；配置没变就不会再调用。修改服务地址或协议后必须重新输入密钥，已保存的密钥不会发给新的地址。把服务切回 Apple 并保存后，对应的密钥会被删除。

## 行为

- **触发时机**：录音结束后自动上传音频转写，有转写后自动生成摘要。
- **失败处理**：第三方服务调用失败时显示错误，不会悄悄换用其他服务。
- **发送的内容**：转写发送音频；摘要发送转写文字和录音标题；提问发送问题、匹配片段和录音标题（最多约 16000 字符）。录音标题可能含人名，请留意。说话人姓名和声纹不会发送。
- **长录音**：超过 20 分钟或 20 MB 的文件会切成最长 20 分钟的 M4A 分段依次上传；某段编码后仍超过 20 MB 时继续对半切分，时间戳都会接回原录音的时间轴。
- **重定向**：服务返回跨域重定向时直接报错，不会跟随，避免密钥发给其他地址。
- **无时间戳的模型**：`gpt-4o-transcribe` 这类只返回纯文字的模型会自动改用 `json` 格式。每个分段只有一条字幕，时间戳和回放定位会很粗。
- **前台运行**：调用使用普通网络请求，不是后台传输。转写长录音时 App 切到后台，请求可能中断，需要重新发起。
